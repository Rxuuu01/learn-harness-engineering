
# Project 01 — Minimal Harness

## Goal
Build an Electron knowledge-base application according to the user's task.

## Project rules
- Work inside the current project directory.
- Use Electron for the desktop application.
- Keep Electron main-process code separate from renderer UI code.
- Use a preload bridge for privileged operations.
- Do not enable Node.js integration in the renderer.
- Store application data in a local persistent directory.

## Workflow
1. Inspect the project structure.
2. Read feature_list.json before implementation.
3. Implement the required features.
4. Install dependencies and start the application.
5. Verify the features and update feature_list.json.
6. Report implemented features, tests, and unresolved issues.

## Completion criteria
- Do not claim completion solely because code was written.
- Verify the application can launch.
- Do not mark a feature as passed without evidence.
- Report failures and unverified functionality explicitly.
